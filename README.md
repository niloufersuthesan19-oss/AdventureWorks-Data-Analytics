# AdventureWorks-BI-Analytics

A Business Intelligence and Data Analytics project using the AdventureWorks dataset. The project demonstrates SQL-based data preparation and analysis, Power BI dashboard development, KPI reporting, customer analysis, product performance, profitability, and return analysis.

## Project Overview

This project analyzes sales transactions to generate business insights across:

- Sales and revenue performance
- Profitability and gross margins
- Product and category performance
- Customer behavior and segmentation
- Regional performance
- Sales trends
- Product returns
- Year-over-year performance

The project was developed using **SQL Server** for data preparation and analysis and **Microsoft Power BI** for interactive dashboard development.

## Tools & Technologies

- **SQL Server** – Data querying, transformation, validation, and analytical views
- **Microsoft Power BI** – Data modeling, DAX, interactive dashboards, and visualization
- **DAX** – KPI calculations, time intelligence, customer analysis, and performance metrics
- **Power Query** – Data transformation and preparation
- **GitHub** – Project documentation and version control
